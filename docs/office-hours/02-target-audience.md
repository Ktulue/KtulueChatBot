# Target Audience

> Office Hours — Builder Mode
> Date: 2026-04-04
> Phase: B2 — Who Would You Show This To

## Context
Asked who Josh would show this to first and what reaction he's going for. Offered stream community, hiring managers, and other builders as options.

## Findings
The primary audience is **Josh himself** — this is a learning vehicle first. The chatbot is how he dives into chatbot/LLM API development. The learning happens vicariously as it's built.

Secondary audiences emerge naturally from the build process:
1. **Portfolio piece** — demonstrates Python + Claude API integration skills, addresses AI Engineering portfolio gaps
2. **Stream content** — building on Software Saturdays, showing work-in-progress examples
3. **Other AI/dev builders** — helping others learn from the process
4. **Website visitors** — functional content on ktulue.com

The project complements SignalSeek (another Python/Claude API project) in Josh's portfolio.

## Key Takeaways
- This is a learning-first project — the journey IS the product
- Portfolio value is a byproduct of genuine learning, not a forced demonstration
- Multiple audiences are served naturally without needing to optimize for any one of them
